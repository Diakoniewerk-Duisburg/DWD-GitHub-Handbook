# Quelle: DWD GitHub Handbook

## Repository

`Diakoniewerk-Duisburg/DWD-GitHub-Handbook`

## Rolle in der Knowledgebase

Das GitHub-Handbook ist eine aktive technische Wissensquelle. Es dokumentiert insbesondere Git, GitHub, Arbeitsweisen, HowTos, Praxisbeispiele, Authentifizierung, Befehlsreferenzen, Troubleshooting, Sicherheit, Lernpfade und Checklisten.

## Umgang mit der Quelle

- Das bestehende Repository bleibt eigenstaendig.
- Inhalte werden nicht ungeprueft dupliziert.
- Relevante Inhalte werden nach dem Wissensmodell klassifiziert.
- Bei einer abgeleiteten Wissensseite wird die GitHub-Quelle angegeben.
- Aenderungen an der technischen Primärquelle erfolgen weiterhin im jeweiligen GitHub-Repository.

## Aktueller Bestand

Die bestehende Struktur umfasst unter anderem `00_Governance`, `01_Grundlagen`, `02_GitHub_Online`, `03_Arbeitsweise`, `04_HowTos`, `05_Praxisbeispiele`, `06_Authentifizierung`, `07_Befehlsreferenz`, `08_Troubleshooting`, `09_Sicherheit`, `10_Lernpfad` und `11_Checklisten`.

## Ziel

Das Handbook bildet damit den GitHub-/Entwicklungsanteil der uebergeordneten DWD M365 Knowledgebase und bleibt gleichzeitig als eigenstaendiges Handbuch nutzbar.
