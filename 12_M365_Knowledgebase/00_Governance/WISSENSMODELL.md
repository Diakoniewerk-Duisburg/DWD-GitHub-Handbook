# Wissensmodell

## Zweck

Das Wissensmodell legt fest, welche Arten von Wissen und welche Wissensdomänen in der Knowledgebase geführt werden.

## Wissensdomänen

Die Knowledgebase ist domänenorientiert aufgebaut. Microsoft 365, SharePoint, Power Platform, Copilot und GitHub sind gleichrangige Domänen. Ergänzend gibt es querschnittliche Domänen für Daten, Prozesse, Architektur, Entwicklung, Betrieb, Sicherheit und Projektwissen.

## Wissensarten

| Wissensart | Bedeutung | Beispiel |
|---|---|---|
| Fachwissen | Fachliche Zusammenhänge und Regeln | Beschaffungsprozess |
| Technisches Wissen | Technische Umsetzung | SharePoint-Architektur |
| Organisationswissen | Aufbau und Zuständigkeiten | Organisationsstruktur |
| Prozesswissen | Abläufe und Verantwortlichkeiten | Genehmigungsworkflow |
| Architekturentscheidung | Verbindliche technische Entscheidung | Berechtigungsmodell |
| Standard | Verbindliche Vorgabe | Namenskonvention |
| Pattern | Wiederverwendbares Lösungsmuster | Power Automate Fehlerbehandlung |
| HowTo | Konkrete Handlungsanleitung | Repository synchronisieren |
| FAQ | Frage und belastbare Antwort | Wo liegt die zentrale Liste? |
| Referenz | Nachschlageinformation | Graph-Endpunkt |
| Projektnachweis | Projektbezogener Stand oder Nachweis | Projektentscheidung |

## GitHub als Wissensdomäne

GitHub ist kein reiner Quelltyp. Die Domäne `06_GitHub` umfasst das eigene Wissen über Git und GitHub: Grundlagen, Arbeitsweisen, Repositories, Branches, Commits, Pull Requests, Actions, Authentifizierung, Sicherheit, Befehlsreferenzen, Troubleshooting, HowTos, Praxisbeispiele und Lernpfade.

Das bestehende `DWD-GitHub-Handbook` bleibt dabei eine operative Primärquelle für dieses Wissen. Quelle und Wissensdomäne sind bewusst getrennt modelliert.

## Verbindlichkeit

Jedes relevante Wissensobjekt soll seinen Status erkennen lassen:

- Entwurf
- In_Pruefung
- Freigegeben
- Verbindlich
- Veraltet
- Ersetzt

## Grundregel

Ein Inhalt soll möglichst genau eine fachliche Primärquelle besitzen. Andere Systeme und Domänen referenzieren diese Quelle, statt konkurrierende Kopien zu erzeugen. Die Einordnung in eine Wissensdomäne und die Angabe der Primärquelle sind zwei unterschiedliche Eigenschaften.
