# Checklisten

## Zweck

Die Checklisten dienen als kurze praktische Kontrolle für wiederkehrende Aufgaben bei der Arbeit mit Git und GitHub.

Sie ersetzen keine ausführlichen HowTos.

Wenn eine Aufgabe zum ersten Mal durchgeführt wird oder ein Problem auftritt, sollte die entsprechende ausführliche Dokumentation verwendet werden.

## Verfügbare Checklisten

### Repository

- `Repository_anlegen.md`
- `Repository_uebertragen.md`

### Synchronisation

- `Repository_synchronisieren.md`

## Grundprinzip

```text
Aufgabe
  ↓
Checkliste
  ↓
Schritte durchführen
  ↓
Ergebnis kontrollieren
```

## Sicherheitsgrundsatz

Vor jedem Commit und Push ist sicherzustellen, dass keine vertraulichen Informationen, Zugangsdaten oder Secrets enthalten sind.
