# Checkliste – GitHub Repository anlegen

## 1. GitHub

- [ ] GitHub-Konto vorhanden
- [ ] GitHub geöffnet
- [ ] Neues Repository ausgewählt
- [ ] Eindeutigen Repository-Namen festgelegt
- [ ] Beschreibung eingetragen
- [ ] Sichtbarkeit geprüft
- [ ] README erstellt
- [ ] Repository erstellt

## 2. Repository prüfen

- [ ] Repository ist erreichbar
- [ ] README vorhanden
- [ ] Repository-Name korrekt
- [ ] Sichtbarkeit korrekt
- [ ] Branch `main` vorhanden

## 3. Lokale Verbindung

Falls lokal gearbeitet werden soll:

- [ ] Repository-URL ermittelt
- [ ] Lokalen Zielordner festgelegt
- [ ] Repository geklont
- [ ] `git status` ausgeführt
- [ ] `git remote -v` geprüft

## 4. Abschluss

- [ ] Repository enthält erwartete Dateien
- [ ] Lokales Repository ist korrekt mit GitHub verbunden
