# HowTos

## Zweck

Dieser Bereich enthält vollständige Schritt-für-Schritt-Anleitungen für konkrete Aufgaben mit Git und GitHub.

Ein HowTo beschreibt einen vollständigen Vorgang von der Ausgangssituation bis zur Kontrolle des Ergebnisses.

## Aufbau eines HowTos

Ein HowTo sollte grundsätzlich enthalten:

1. Ziel
2. Ausgangssituation
3. Voraussetzungen
4. Vorbereitung
5. Durchführung
6. Kontrolle
7. Typische Fehler
8. Erfolgreicher Endzustand

## HowTo oder Praxisbeispiel?

### HowTo

Ein HowTo beantwortet die Frage:

> **Wie führe ich eine vollständige Aufgabe sauber durch?**

Es enthält alle erforderlichen Schritte.

### Praxisbeispiel

Ein Praxisbeispiel beschreibt eine konkrete typische Situation kompakter und hilft beim Verständnis eines Problems oder Arbeitsablaufs.

## Grundregel

Ein HowTo soll so geschrieben sein, dass der beschriebene Vorgang nachvollziehbar und reproduzierbar durchgeführt werden kann.

Technische Details werden nur aufgenommen, wenn sie für das Verständnis oder die sichere Durchführung erforderlich sind.
