# HowTos

Dieser Bereich enthält vollständige Schritt-für-Schritt-Anleitungen für typische Aufgaben mit Git und GitHub.

Die HowTos bauen auf den Grundlagen und den beschriebenen Arbeitsweisen des Handbuchs auf und sollen eine konkrete Aufgabe vollständig nachvollziehbar machen.

## Ziel

Ein HowTo soll die Frage beantworten:

> Wie führe ich eine bestimmte Aufgabe mit Git und GitHub sicher und nachvollziehbar durch?

Dabei werden nicht nur die notwendigen Befehle beschrieben, sondern auch die Prüfungen vor und nach der Durchführung.

## Struktur eines HowTos

Ein vollständiges HowTo enthält grundsätzlich:

1. Ziel
2. Ausgangssituation
3. Voraussetzungen
4. Vorbereitung
5. Durchführung
6. Kontrolle
7. Typische Fehler
8. Ergebnis

## Grundprinzip

Bei allen HowTos gilt:

```text
Ausgangssituation
       ↓
Vorbereitung
       ↓
Durchführung
       ↓
Kontrolle
       ↓
Ergebnis
```

Die Kontrolle ist ein eigenständiger Bestandteil des Vorgangs. Ein Git-Befehl ohne anschließende Prüfung gilt nicht automatisch als erfolgreicher Abschluss.
