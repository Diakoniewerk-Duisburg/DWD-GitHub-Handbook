# DWD-Copilot-Anwendungsfaelle

## Zweck

Hier werden konkrete DWD-Fachprobleme als potenzielle Copilot-/Agenten-Anwendungsfaelle beschrieben. Die Eintraege sind keine Produktivfreigaben.

## Kandidaten

| Anwendungsfall | Fachlicher Bezug | Moegliche Funktion |
|---|---|---|
| Wissensagent | SharePoint / M365 | Fragen und Antworten auf freigegebenem Organisationswissen |
| Beschaffungsagent | Beschaffung | Recherche, Vorbereitung und Prozessunterstuetzung |
| Genehmigungsagent | Genehmigungsprozesse | Pruefung, Vorbereitung und kontrollierte Workflow-Aktionen |
| Ticketagent | Ticketsystem | Klassifikation, Recherche und Vorgangsbearbeitung |
| Provisioningagent | M365-Provisioning | Vorbereitung und kontrollierte technische Aktionen |
| Datenmigrationsagent | Datenmigration | Analyse, Qualitaetspruefung und Vorbereitung |
| Adressbuchagent | Zentrales Adressbuch | Suche und Bereitstellung von Organisationsinformationen |

## Bewertungsregel

Ein Kandidat wird erst dann zu einem konkreten Agenten, wenn Zweck, Daten, Wissensquellen, Berechtigungen, Aktionen, Autonomie, Owner, Tests und Governance nach dem DWD-Agentenstandard beschrieben sind.

Die fachliche Prozessdokumentation bleibt in `08_Prozesse`; die technische Agentenbeschreibung bleibt in `05_Copilot`.
