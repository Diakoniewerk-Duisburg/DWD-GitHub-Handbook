# Microsoft 365 Copilot – Varianten und Funktionen

## Einordnung

Microsoft 365 Copilot ist die zentrale Benutzererfahrung fuer KI-gestuetzte Arbeit in Microsoft 365. Darueber koennen allgemeine Copilot-Funktionen, spezialisierte Agents und benutzerdefinierte Agents erreichbar sein.

Die Begriffe **Microsoft 365 Copilot**, **Agent**, **Copilot Studio** und **GitHub Copilot** sind nicht synonym.

## Wichtige Varianten

| Variante | Rolle | Typischer Nutzen |
|---|---|---|
| **Microsoft 365 Copilot** | allgemeine Copilot-Erfahrung | Fragen, Zusammenfassen, Erstellen, Analysieren und Arbeiten mit M365-Kontext |
| **Researcher** | Recherche-Agent | mehrstufige Recherche und strukturierte Ergebnisse |
| **Analyst** | Analyse-Agent | strukturierte Datenanalyse und Ursachenanalyse |
| **Declarative Agent / Agent fuer Microsoft 365 Copilot** | spezialisierter Agent | definiertes DWD-Fachwissen innerhalb der M365-Copilot-Erfahrung |
| **Custom Agent** | erweiterter Agent | spezialisierte Aufgaben mit Wissen und Tools |

## Researcher

Researcher ist fuer mehrstufige Rechercheaufgaben ausgelegt. Er kann Informationen aus geeigneten Quellen zusammenfuehren und daraus strukturierte Ergebnisse erstellen.

Geeignet fuer:

- Markt- und Unternehmensrecherche,
- Entscheidungsgrundlagen,
- Zusammenstellung mehrerer Quellen,
- Rechercheintensive Fachaufgaben.

## Analyst

Analyst ist auf anspruchsvollere Analyseaufgaben ausgerichtet.

Geeignet fuer:

- Datenanalyse,
- Mustererkennung,
- Ursachenanalyse,
- Auswertung groesserer Datenmengen,
- fachliche Untersuchungen.

## Agents fuer Microsoft 365 Copilot

Spezialisierte Agents koennen Microsoft 365 Copilot um organisations- oder fachbereichsspezifisches Wissen erweitern.

DWD-Beispiele waeren grundsaetzlich denkbar fuer:

- Organisationswissen,
- Richtlinienwissen,
- SharePoint-Fachwissen,
- Prozesswissen,
- definierte interne Wissensbereiche.

Ein solcher Agent muss dabei immer auf seine vorgesehenen Wissensquellen und Benutzergruppen begrenzt werden.

## Abgrenzung zu Copilot Studio

Wenn ein Agent nur spezialisiert antworten und vorhandenes Wissen bereitstellen soll, kann ein Agent fuer Microsoft 365 Copilot ausreichend sein.

Wenn ein Agent dagegen komplexe Aktionen, mehrere Unternehmenssysteme, APIs, MCP, Workflows oder einen umfangreichen Lebenszyklus benoetigt, ist Copilot Studio zu bewerten.

## DWD-Entscheidungsregel

**Wissen bereitstellen:** Microsoft 365 Copilot / spezialisierter Agent.

**Recherche durchfuehren:** Researcher.

**Daten untersuchen:** Analyst.

**Geschaeftsprozess ausfuehren:** Copilot Studio.

**Komplexe mehrstufige Agentenarbeit:** geeigneten Copilot-Studio-Harness bewerten.
