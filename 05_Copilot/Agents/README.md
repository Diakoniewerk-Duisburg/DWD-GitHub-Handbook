## Einordnung

Im Copilot-Umfeld muessen mehrere Ebenen getrennt werden:

1. **Copilot-Erfahrungen** – z. B. Microsoft 365 Copilot oder GitHub Copilot.
2. **Vorgefertigte Agents** – z. B. Researcher oder Analyst.
3. **Fachagenten** – z. B. Finance Agent oder Security Agents.
4. **Agentenplattformen** – z. B. Copilot Studio.
5. **Agent-Harnesses** – Standard Harness, Copilot Chat Harness und GitHub Copilot Harness.
6. **Eigene Agents** – fuer organisations- oder prozessspezifische Aufgaben.
7. **Agentische Erweiterungen** – z. B. GitHub Agent Skills und MCP.

Die Einordnung ist wichtig, weil sich Funktionen, Berechtigungen, Lizenzierung, Datenquellen, Ausfuehrungsumgebung und Governance unterscheiden koennen.

## DWD-Grundsatz

Ein Agent wird nicht danach ausgewaehlt, wie beeindruckend seine KI-Funktion wirkt, sondern danach, welches konkrete Problem geloest werden soll, welche Daten benoetigt werden, welche Laufzeit geeignet ist und ob der Agent nur informieren oder auch handeln darf.
