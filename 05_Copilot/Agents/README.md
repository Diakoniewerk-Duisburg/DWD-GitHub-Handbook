## Einordnung

Im Microsoft-Copilot-Umfeld muessen unterschiedliche Konzepte getrennt werden:

1. **Vorgefertigte Microsoft-Agents** – z. B. Researcher oder Analyst.
2. **Fachagenten** – z. B. Finance Agent oder Security Analyst.
3. **Agent-Harness / Plattformen** – z. B. der GitHub Copilot Harness in Copilot Studio.
4. **Eigene Agents** – fuer organisations- oder prozessspezifische Aufgaben.
5. **GitHub-agentische Funktionen** – Cloud Agent, Agent Mode, Code Review, Skills, Workflows und MCP.

Die Einordnung ist wichtig, weil sich Funktionen, Berechtigungen, Lizenzierung, Datenquellen, Ausfuehrungsumgebung und Governance deutlich unterscheiden koennen.

## DWD-Grundsatz

Ein Agent wird nicht danach ausgewaehlt, wie beeindruckend seine KI-Funktion wirkt, sondern danach, welches konkrete Problem geloest werden soll, welche Daten benoetigt werden und ob der Agent nur informieren oder auch handeln darf.
