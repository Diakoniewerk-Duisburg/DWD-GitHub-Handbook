# Agenten-Patterns

Dieser Bereich beschreibt wiederverwendbare Architektur- und Umsetzungsmuster fuer DWD-Agents.

## Patterns

- [Human-in-the-Loop](Human_in_the_Loop.md) – menschliche Kontrolle vor folgenreichen Aktionen
- [Agenten-Orchestrierung](Agenten_Orchestrierung.md) – Zusammenarbeit spezialisierter Agents

## Geplante Erweiterungen

Weitere Patterns werden aus konkreten DWD-Anwendungsfaellen abgeleitet. Beispiele sind Wissensagent, Rechercheagent, Analyseagent, Prozessagent und Aktionsagent.
