# DWD M365 Knowledgebase

Zentrale Wissensarchitektur fuer Microsoft 365, SharePoint, Power Platform, Copilot und GitHub sowie fuer Daten, Prozesse, Architektur, Entwicklung, Betrieb, Sicherheit und Projektwissen.

## Grundsatz

GitHub ist eine **gleichberechtigte Wissensdomäne** neben Microsoft 365, SharePoint, Power Platform und Copilot.

Die bestehende GitHub-Dokumentation wird in die Domäne `06_GitHub` eingeordnet. Inhalte werden dabei fachlich neu strukturiert, ohne Wissen unkontrolliert zu duplizieren.

## Zielstruktur

Siehe die Ordnerstruktur dieses Repositorys. Die Nummerierung bildet die verbindliche Wissensarchitektur ab.

## Dokumentationsregeln

- Dokumentation auf Deutsch.
- Ordner- und Dateinamen ohne Umlaute.
- Verbindliche Aussagen werden von Entwuerfen und Empfehlungen getrennt.
- Primaerquellen werden eindeutig gekennzeichnet.
- Bestehendes Wissen wird vor einer Neuerstellung geprueft.
