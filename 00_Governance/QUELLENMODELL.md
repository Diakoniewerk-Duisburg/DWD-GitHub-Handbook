# Quellenmodell

## Ziel

Das Quellenmodell beschreibt die Herkunft eines Wissensobjekts. Es ist von der Wissensdomäne zu unterscheiden.

## Grundsatz

**Domäne beantwortet: Wo gehoert das Wissen fachlich hin?**

**Quelle beantwortet: Woher stammt die Aussage?**

Eine Quelle ist deshalb nicht automatisch eine eigene Wissensdomäne.

## Primaere Quellen

| Bereich | Typische Primaerquelle |
|---|---|
| GitHub | DWD-GitHub-Handbook und jeweilige GitHub-Repositories |
| Microsoft 365 | Microsoft-Dokumentation und freigegebene DWD-Dokumentation |
| SharePoint | freigegebene DWD-Fach- und Technikdokumentation |
| Power Platform | freigegebene Loesungs- und Technikdokumentation |
| Copilot | freigegebene Governance-, Agent- und Wissensquellen |
| Fachprozesse | freigegebene DWD-Dokumentation |
| Organisation | freigegebene DWD-Organisationsquelle |
| Projekte | jeweilige Projektdokumentation |

## GitHub

Das bestehende `DWD-GitHub-Handbook` bleibt die operative Primaerquelle fuer die dort bereits dokumentierte Git- und GitHub-Arbeitsweise. Die Knowledgebase ordnet dieses Wissen in `06_GitHub` ein.

Es wird nicht als zweite konkurrierende Dokumentation gepflegt.
